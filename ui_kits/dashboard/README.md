# Dashboard UI Kit — Quietluxe

A high-fidelity recreation of the in-product dashboard surface. Click
`index.html` for an interactive demo (sidebar nav switches the main view).

## Files

| File | Description |
| --- | --- |
| `index.html` | Demo app with sidebar nav, topbar, dashboard view |
| `Sidebar.jsx` | Left rail with workspace switcher + nav items |
| `Topbar.jsx` | Search, notifications, account |
| `StatCard.jsx` | Metric card (numeral, label, value, trend line) |
| `WeeklyDigest.jsx` | Editorial digest panel — the marquee surface |
| `DataTable.jsx` | Quiet hairline-only table with status pills |

All components consume tokens from `../../colors_and_type.css`.
