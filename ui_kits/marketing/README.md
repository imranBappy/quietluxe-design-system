# Marketing UI Kit — Quietluxe

A high-fidelity recreation of the marketing surface for a Quietluxe-branded
product. Click `index.html` for the demo. Components live as small,
reusable JSX files.

## Files

| File | Description |
| --- | --- |
| `index.html` | Demo marketing page (hero, features, quote, CTA, footer) |
| `Nav.jsx` | Top nav with wordmark, links, primary CTA |
| `Hero.jsx` | Editorial hero: numeral, label, italic-emphasis title, two CTAs |
| `FeatureGrid.jsx` | Three asymmetric feature blocks with Lucide icons |
| `Quote.jsx` | Centered editorial pull-quote, italic serif |
| `CTA.jsx` | Final call-to-action band on cream surface |
| `Footer.jsx` | Hairline-divided footer columns |

All components consume tokens from `../../colors_and_type.css`. No real
photography ships with the kit — feature blocks use restrained line-art
placeholders styled in token colors.
